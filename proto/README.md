# proto — 거리 기반 자동 배정 시스템 (#157617) 라이브 프로토타입

클릭 가능한 React 관리자 콘솔. 추가 도입 검토 항목 2~5(모델 82~85)의 형상 시연용이며, 전 데이터는 가상(데모 데이터 배지 상시 표시).

## 실행

- `index.html`을 브라우저에서 열면 바로 동작합니다 (React 18 + Babel + Tailwind CDN — 빌드 불필요, 인터넷 연결 필요).
- 권장: `python3 -m http.server` 후 `http://localhost:8000/` 접속. 1024px 이상 해상도 전제(미만이면 안내 오버레이).

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 앱 셸 — 사이드바 라우팅, Tweaks 패널, `window.__navigate` 노출(demo 트랙 의존) |
| `data.js` | 데모 데이터 원장 — 김OO·박OO·이OO·최OO, APL-* ID, 두리엔지 회수 스토리, 서진금속 실패+재배정 쌍, 프리셋 2세트 |
| `components.jsx` / `tweaks-panel.jsx` | 공용 컴포넌트·Tweaks 셸 (스킬 템플릿 원본 그대로) |
| `dashboard.jsx` | 01 배정 현황 모니터 (모델 82) — KPI 4종·도별 편차 게이지·부하 히트맵·오늘 처리할 것 |
| `console.jsx` | 02 실패 건 처리 (모델 83) — 인박스 + 4스텝 수동 재배정 위저드·회수 탭 |
| `history.jsx` | 03 이력·통계 (모델 84) — 행 클릭 "왜 이 전문가?" XAI 카드 + 후보 비교표 펼침 |
| `templates.jsx` | 04 파라미터·시뮬레이션 (모델 85) — 프리셋 A/B 비교(▲▼ 델타)·적용 확인·롤백 |

## 시연 포인트

- 우하단 "Tweaks 열기" → 정책 모드(거리 우선/균등 우선) 전환 시 콘솔 2단계 후보 카드의 정렬·추천이 실제로 바뀝니다.
- 편차 상한 초과 후보(최OO) 선택 → 확정 시 경고 다이얼로그(BS0089, 차단 아님) → 이력 기록 토스트(BS0087).
- 파라미터 화면 <이 설정 적용>은 제안 설정 드라이런(B 슬롯) 실행 전에는 비활성(BS0093). 적용하면 대시보드 게이지도 새 허용 편차로 재계산됩니다.
